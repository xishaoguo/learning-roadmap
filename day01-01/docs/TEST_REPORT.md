## 7. 缺陷与处理记录

### ENV-01 EC2 公网访问失败

- 现象：服务器内部 HTTPS 检查正常，但公网浏览器无法打开页面。
- 根因：EC2 安全组未正确允许所需的公网入站流量。
- 处理：修正安全组规则，开放 TCP 80 与 443。
- 复测：公网首页、JavaScript 和图片资源均返回 HTTP 200。
- 状态：已关闭。

### TEST-01 测试用例 DOM 未隔离

- 现象：首轮测试中后续用例匹配到多个相同元素。
- 根因：Vitest 环境未在每个用例后清理已渲染 DOM。
- 处理：在测试 setup 中增加 `afterEach(cleanup)`。
- 复测：5 个自动化用例全部通过。
- 状态：已关闭；该问题只影响测试环境，不影响产品运行。

## 8. 当前已知限制

- 房源、收藏和用户数据均为前端演示数据，刷新后恢复默认状态。
- 联系房东仅展示前端成功反馈，未发送真实请求。
- 分享、地图、登录、消息、预约、租约和支付尚未接入真实服务。
- 本轮未覆盖弱网、低端设备、旧版浏览器及大规模数据性能测试。
- 尚未开展真实接口安全测试、渗透测试和无障碍专项审计。

## 9. 发布结论

当前版本的核心演示链路、生产构建与线上静态站点均验证通过，可以作为产品演示和后续接口开发的前端基线。正式业务上线前，需要补齐真实后端、数据持久化、表单校验、监控告警及专项安全测试。
